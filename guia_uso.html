Como usar

Passo a passo

Faça os passos de configuração uma vez. Depois, para cada solicitação, siga do cadastro do aluno até a emissão do documento.

00

Acesse o sistema

Primeira abertura e login

  1. No Windows, abra run_sistema.bat. Na primeira execução, ele prepara o ambiente Python e instala as dependências.
  2. Se ainda não houver conta, crie o primeiro usuário administrador na tela de acesso. Nas próximas vezes, entre com seu usuário e senha.
  3. Se o administrador criou sua conta com senha provisória, troque-a no primeiro login. Para trocar depois, use Alterar senha no topo da janela.
Se iniciar pelo VS Code, use a tarefa R.A - Equivalencias: iniciar interface com Ctrl+Shift+B. A extensão Code Runner pode executar sem exibir corretamente a janela Tkinter.
01

Configure o ano, o código e as planilhas

Menu Configurações (Planilha)

  1. Informe o Ano letivo que será usado nos próximos códigos.
  2. Informe o início do código (prefixo), como PROC ou APROV.
  3. Escolha a planilha principal de processos e a base separada de alunos. Por padrão, são Base_Equivalencias_Senac.xlsx e Base_Alunos.xlsx.
  4. Clique em Salvar e conectar.
Os novos processos recebem códigos no formato PREFIXO-ANO-001. Exemplo: prefixo PROC e ano 2026 geram PROC-2026-001. A numeração continua a partir do maior código existente para aquele prefixo e ano.
02

Cadastre ou importe o aluno

Menu Cadastro de Alunos

O aluno fica pré-cadastrado na base separada até ser selecionado em uma solicitação.

  • Cadastro manual: preencha ID, nome, RG, CPF, data de nascimento e data de matrícula; depois clique em Salvar pré-cadastro.
  • Importação por PDF: clique em Importar alunos (PDF) e selecione o relatório. O sistema procura ID, nome, RG, CPF, nascimento e matrícula no layout tabular do relatório do Senac.
  • Use o campo de busca para localizar um pré-cadastro. Selecione uma linha para revisar ou atualizar os dados.
O PDF precisa conter texto selecionável. Se for apenas uma imagem digitalizada, o sistema não consegue extrair os campos automaticamente.
03

Abra uma solicitação de aproveitamento

Menu Solicitar Aproveitamento

  1. Para uma nova solicitação, selecione um aluno pré-cadastrado no campo correspondente. Os dados conhecidos do aluno serão preenchidos.
  2. O sistema sugere o próximo ID com base no prefixo e no ano configurados. Confira os dados do aluno, curso de origem e destino, oferta, status e demais campos.
  3. Clique em Salvar cadastro. O processo é salvo na planilha principal e o vínculo com o aluno é registrado na base de alunos pelo ID do processo.
  4. Para consultar um processo, pesquise por ID, matrícula ou outros dados. Se houver vários resultados, escolha o processo na lista. Também é possível usar o seletor Processo ativo no topo da janela.
  5. Edite os campos necessários e salve novamente. Para começar outro, clique em Novo cadastro.
04

Registre as equivalências de UCs

Menu Equivalência de UCs

  1. Selecione primeiro o processo ativo no topo da janela.
  2. Clique em Adicionar UC e informe os dados da unidade cursada e da unidade de destino. Os campos de escolha de UC oferecem opções de UC-1 a UC-25.
  3. As alterações são salvas no processo selecionado. Use Editar selecionada ou Remover para corrigir a tabela.
  4. Se precisar de uma planilha do mapeamento, clique em Exportar mapeamento.
05

Gere o requerimento

Menu Requerimento Oficial

  1. Com o processo ativo selecionado, abra Requerimento Oficial e confira a prévia.
  2. Clique em Abrir versão para impressão e escolha onde salvar o arquivo HTML.
  3. O navegador abrirá o documento. Use a impressão do navegador para imprimir ou salvar como PDF.
06

Acompanhe pelo Dashboard

Página inicial do sistema

  • O cartão de total mostra quantos processos estão cadastrados; o de andamento mostra os que ainda não foram encerrados.
  • O gráfico apresenta a quantidade de processos por status.
  • Maior espera em aberto mostra o processo aberto com mais dias desde a data do requerimento, junto do ID, aluno e status.
Processos deferidos, indeferidos ou concluídos não entram no cálculo da maior espera. O painel se atualiza ao abrir a página Dashboard.

Onde os dados ficam

O sistema mantém os cadastros em arquivos Excel separados:

  • Planilha principal: processos, equivalências e usuários.
  • Base de alunos: fichas dos alunos e os IDs dos processos vinculados.

Os caminhos são definidos em Configurações. Feche os arquivos no Excel enquanto o sistema estiver gravando. Faça cópias de segurança dos dois arquivos regularmente.

Contas de usuário

  • Somente usuários com função Administrador veem o botão Usuários para cadastrar outras contas.
  • Ao criar uma conta, defina usuário, função e senha provisória. A pessoa deverá trocar essa senha no primeiro acesso.
  • As senhas são armazenadas como hash protegido na aba Usuarios da planilha principal.
